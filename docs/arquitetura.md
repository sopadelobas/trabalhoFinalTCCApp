# Arquitetura do Sistema - UNIONG

## 📱 Visão Geral
O sistema **UNIONG** é uma solução mobile desenvolvida em **React Native** com **Expo Router** (TypeScript) para roteamento declarativo e gestão de navegação baseada em ficheiros.

## 🗂️ Módulos e Componentes Principais
- **Autenticação:** Sistema de login com alternância dinâmica de perfis (`VOLUNTARIO` e `ONG`) através do `MenuContext`.
- **Módulo de Doações:** Fluxos de doação financeira via PIX (com emissão de comprovativos) e agendamento de entregas/delivery.
- **Engajamento Comunitário (Fortalecer Laços):** Módulo para registo e visualização de pontos de recolha e presenças em eventos.
- **Comunicação Directa:** Interface de canais e chat privado entre voluntários e instituições.
