## 📌 Sobre o Projeto

O **UNIONG** é uma plataforma mobile focada em aproximar voluntários e ONGs, oferecendo catalogação por nicho, geolocalização de pontos de recolha, gestão de doações (PIX e entrega) e comunicação direta entre os utilizadores.

### 🛠️ Tecnologias Utilizadas
- **Mobile:** React Native com Expo (Expo Router, TypeScript)
- **Design:** Figma
- **Controle de Versão:** Git / GitHub

## 🚀 Como Executar o Projeto Mobile

```bash
# Clone o repositório
git clone [https://github.com/seu_usuario/trabalhoFinalTCCApp.git](https://github.com/seu_usuario/trabalhoFinalTCCApp.git)

# Acesse a pasta do projeto
cd trabalhoFinalTCCApp

# Instale as dependências
npm install

# Inicie o servidor do Expo
npx expo start
